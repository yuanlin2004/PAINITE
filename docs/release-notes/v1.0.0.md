# PAINITE 1.0

The first release of PAINITE: AI photo enhancement that runs on your own NVIDIA GPU server, with a Mac app, a Lightroom integration and a command line tool for macOS and Linux.

**User guide:** https://yuanlin2004.github.io/PAINITE/

## What's in it

**Six enhancements**, each using the model that won side-by-side tests on real photos:

| Enhancement | What it does | Model |
| --- | --- | --- |
| Denoise | Removes high-ISO grain and JPEG noise and keeps texture | SCUNet |
| Sharpen | Restores crisp edges to soft photos without halos | Real-ESRGAN 2× |
| Unblur: Motion | Removes camera shake and motion smear | Stripformer (non-commercial) |
| Unblur: Focus | Recovers missed focus | LaKDNet |
| Face | Restores faces from 128 to 1024 px and leaves the rest untouched | GPEN-BFR-1024 + RetinaFace |
| Upscale 2× | Doubles width and height with real detail | 2× NomosUni ESRGAN |

Run up to four of them in one pass, for example denoise, then sharpen, then upscale.

**Mac app** (macOS 14+, Apple silicon)
- Open a JPEG or TIFF and pick steps or a preset (Clean Up, High ISO, Portrait, Rescue Blur, Print 2×). Drag step cards to reorder them.
- A live preview of the area you choose. It's exactly what the export produces. Compare in Split or Side by Side, and hold `\` to see the original.
- Show faces outlines the faces the Face step found.
- Exports keep the color profile and EXIF/XMP/IPTC metadata. Results are checked before they're written, and the original is never overwritten.
- Works as a **Lightroom desktop "Edit in"** editor: Save to Lightroom, then Finish.
- Help › PAINITE User Guide and About PAINITE link to the guide.

**Command line** (`painite`, macOS Apple silicon, Linux x86-64 and ARM64)
- `painite enhance --op denoise:0.6,sharpen:0.3,upscale2x -o out/ *.jpg`: batches run four photos at a time. Everything is checked before upload, results are written atomically, and downloads resume.
- `--json` output and clear exit codes for scripts. `painite version` and `painite help` link to the guide.

**Server** (NVIDIA DGX Spark)
- `install.sh` builds the Docker image, sets up a private TLS certificate, downloads the models after you accept their licenses, and installs a systemd service.
- Per-computer access tokens, a content-addressed upload cache, a job queue with progress, and automatic cleanup of photos and results.
- Black-and-white (grayscale) photos are accepted and come back as RGB.

SHA-256 checksums: `SHA256SUMS` for the command line packages, and a `.sha256` file next to the app and the server. Setup takes about 15 minutes. See [Install](https://yuanlin2004.github.io/PAINITE/install.html).

## Before you start

- **The Mac app isn't notarized yet.** The first time you open it, macOS blocks it. Click **Open Anyway** in System Settings › Privacy & Security, or run `xattr -dr com.apple.quarantine /Applications/PAINITE.app`.
- **Model licenses are separate from PAINITE's.** No weights are bundled. The server downloads them from their authors (or from PAINITE's unchanged mirror in the `models-v1` release) after you accept each license. **Motion unblur (Stripformer) is for non-commercial use only**, and Focus unblur (LaKDNet) is AGPL-3.0. See [Licenses](https://yuanlin2004.github.io/PAINITE/help.html#licenses).
- The server is tested on the NVIDIA DGX Spark. Other Linux machines with an NVIDIA GPU and Docker should work but haven't been tested.
