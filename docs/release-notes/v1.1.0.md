# PAINITE 1.1

PAINITE now works with AI agents. The `painite` command includes an MCP server, so Claude Code, Claude Desktop and other MCP clients can check your server, preview an enhancement and enhance photos on your computer for you.

**User guide:** https://yuanlin2004.github.io/PAINITE/ · **AI agents:** https://yuanlin2004.github.io/PAINITE/agents.html

## What's new

**`painite mcp`: an MCP server for AI agents**

```sh
claude mcp add painite -- painite mcp
```

For Claude Desktop, add `painite` with the argument `mcp` to `claude_desktop_config.json` (see the guide). It uses your existing `painite` settings, certificate and token, so there's nothing else to set up. Photos still go only to your own server.

Agents get seven tools:

| Tool | What it does |
| --- | --- |
| `server_status` | Server health, GPU and queue, the enhancements with their strength ranges and models, and limits |
| `enhance_photos` | Enhances one or more photos with one step or a pipeline of up to four, and saves the results. Same checks and safe writes as `painite enhance` |
| `preview_enhancement` | Renders one area of a photo and shows it to the agent as an image, so it can compare settings before a full run. Reports the faces found |
| `submit_job`, `get_job`, `download_result`, `cancel_job` | Start long jobs, check on them, save results and cancel |

Try asking: "Is my PAINITE server up?", "Preview denoise at 0.6 on ~/Pictures/night.jpg", or "Restore the faces in these old portraits into ~/Pictures/restored".

**Also in this release**
- The guide lists the GeForce RTX 4070 (12 GB) on Ubuntu as a tested server, and explains the NVIDIA driver 580 requirement.
- The guide's download links now always point at the latest release.

The Mac app and the server are unchanged apart from their version number. Updating them is optional.

## Before you start

- **They aren't notarized yet**, so macOS blocks files downloaded in a browser. Download the command with `curl` as the [install guide](https://yuanlin2004.github.io/PAINITE/install.html#cli) shows, or run `xattr -d com.apple.quarantine ./painite` after unpacking. For the app, click **Open Anyway** in System Settings › Privacy & Security.
- In Claude Desktop, use the full path to `painite` (from `which painite`), because Desktop doesn't use your shell's `PATH`.
- **Model licenses are separate from PAINITE's.** Motion unblur (Stripformer) is for non-commercial use only, and Focus unblur (LaKDNet) is AGPL-3.0. See [Licenses](https://yuanlin2004.github.io/PAINITE/help.html#licenses).
