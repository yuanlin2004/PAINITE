# PAINITE 1.2

The PAINITE server now runs on a Mac with Apple silicon, so you no longer need an NVIDIA machine to try PAINITE. Face restoration now changes only the face, and previews are much faster.

**User guide:** https://yuanlin2004.github.io/PAINITE/ · **Server on a Mac:** https://yuanlin2004.github.io/PAINITE/install.html#mac-server

## What's new

**Run the server on your Mac**

The server tarball now includes `install-mac.sh`. It runs the same models on the Mac's GPU (PyTorch with Metal), with no Docker. Run it as yourself, not with sudo:

```sh
curl -LO https://github.com/yuanlin2004/PAINITE/releases/download/v1.2.0/painite-server_1.2.0.tar.gz
tar xzf painite-server_1.2.0.tar.gz
cd painite-server_1.2.0
./install-mac.sh
```

It needs [uv](https://docs.astral.sh/uv/) (`brew install uv`) or Python 3.11 or newer. It installs the `painite-server` command in `~/.local/bin`, keeps its data in `~/Library/Application Support/painite-server`, and starts the server at login on `https://localhost:8443`. Add `--lan` to let other computers use it too, and `--uninstall` to remove it.

On an M2 Pro with 16 GB, previews take 3 to 5 seconds, and a full 24 MP photo takes 1.2 to 2.1 minutes depending on the enhancement (a DGX Spark takes about 30 seconds). The server uses up to about 9 GB of memory. The Mac app, Lightroom **Edit in** and the command line work with it the same way as with a Spark.

**Face restoration changes only the face**

The face model (`face/gpen-bfr-1024@1.1.0`) now finds the face's own pixels with face parsing (BiSeNet) and pastes back only those. Hands, fingers, arms, hair, scarves and background near a face keep their original pixels, and there's no more bright halo around hair against the sky.

**Faster previews**

- The server renders only the tiles under the preview, so a first preview is several times faster: about 4 seconds instead of 17 on a DGX Spark, and instead of 20 to 30 on a Mac.
- It keeps recent model output in memory, so changing only the strength updates the preview in under a second (about 0.5 s on a DGX Spark, 0.1 s on a Mac). `PAINITE_TILE_CACHE_MB` sets the cache size (512 MB by default).
- The 1.2 Mac app asks for previews that line up with the server's tiles, so its preview area is slightly smaller than before. Older apps still work and get faster previews too.

Previews still match the full export pixel for pixel.

## Upgrading

- **Server on a DGX Spark or Linux PC:** unpack the new release and run `sudo ./install.sh` again. When it asks, accept the model licenses so it downloads the new face model. Or, after upgrading, run `sudo painite-server models pull face/gpen-bfr-1024@1.1.0 --accept-license` and `sudo systemctl restart painite-server`. Until the new face model is installed, the server keeps using the old one. Once it is, you can free about 450 MB with `sudo painite-server models remove face/gpen-bfr-1024@1.0.0`.
- **Server on a Mac:** new in this release; see above.
- **Mac app:** replace it in Applications.
- **Command line:** unchanged apart from its version number, so updating it is optional.

## Before you start

- **The downloads aren't notarized yet**, so macOS blocks files downloaded in a browser. Download with `curl` as shown above and in the [install guide](https://yuanlin2004.github.io/PAINITE/install.html), or run `xattr -d com.apple.quarantine <file>`. For the app, click **Open Anyway** in System Settings › Privacy & Security.
- **Model licenses are separate from PAINITE's.** Motion unblur (Stripformer) is for non-commercial use only, and Focus unblur (LaKDNet) is AGPL-3.0. See [Licenses](https://yuanlin2004.github.io/PAINITE/help.html#licenses).
