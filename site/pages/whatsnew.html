PAINITE 1.2

November 23, 2026 · Release notes

Run the server on your Mac

The server now runs on a Mac with Apple silicon, using the Mac's GPU, with no Docker. You no longer need an NVIDIA machine to try PAINITE, and the Mac app can use a server on the same Mac. The server download includes install-mac.sh; see Server on a Mac. On an M2 Pro, previews take 3 to 5 seconds and a 24-megapixel photo takes 1 to 2 minutes.

Face restoration changes only the face

The Face enhancement now finds the face's own pixels and restores only those. Hands, fingers, arms, hair, scarves and background next to a face keep their original pixels, and there's no bright halo around hair against the sky. Existing servers need the new face model: see Upgrading.

Faster previews

The server renders only the part of the photo under the preview and remembers recent results, so a first preview takes about 4 seconds instead of 17 on a DGX Spark, and changing only the strength updates it in under a second. Previews still match the export pixel for pixel. The 1.2 Mac app's preview area is slightly smaller than before, so that it lines up with the server's tiles.

PAINITE 1.1

November 22, 2026 · Release notes

AI agents can use PAINITE

The painite command includes an MCP server, painite mcp. Claude Code, Claude Desktop and other MCP clients can check your server, preview an enhancement and enhance photos on your computer for you. See AI agents.

More tested hardware

The server is tested on a Ubuntu PC with a GeForce RTX 4070 (12 GB), which needs NVIDIA driver 580 or newer.

PAINITE 1.0

November 22, 2026 · Release notes

The first release: AI photo enhancement on your own GPU server.

  • Six enhancements: denoise, sharpen, unblur (motion and focus), face restoration and 2× upscale. Up to four run in one pass.
  • Mac app: a live before/after preview of the area you choose, presets, and exports that keep the color profile and metadata. Works as a Lightroom desktop Edit in editor.
  • Command line: painite for macOS and Linux, for single photos and batches.
  • Server: one installer for the NVIDIA DGX Spark, with a private certificate, per-computer tokens and model downloads after you accept their licenses.
