Troubleshooting

The server commands below are for a DGX Spark or Linux server. On a server on a Mac, run painite-server without sudo, and instead of sudo systemctl restart painite-server run launchctl kickstart -k gui/$(id -u)/com.painite.server.

The app or painite status can't reach the server

  • Check that the server is running: systemctl status painite-server on the server. Its log is in journalctl -u painite-server. For a server on a Mac, run launchctl print gui/$(id -u)/com.painite.server; its log is ~/Library/Logs/painite-server.log.
  • Use the same name or IP address that the certificate covers (the installer prints them). To add a name, run sudo ./install.sh --hostname name again. Clients stay trusted.
  • On a Mac, allow PAINITE in System Settings › Privacy & Security › Local Network.
  • The server uses port 8443. Make sure a firewall doesn't block it.

“Certificate not trusted” or a fingerprint mismatch

Get the fingerprint on the server with sudo painite-server admin fingerprint and trust it again: painite trust --fingerprint SHA256:…, or Trust in the Mac app's Settings. If the server was reinstalled with --new-ca, every computer has to trust it again.

“Unauthorized”

The token is wrong or was revoked. Create a new one on the server with sudo painite-server token create --name computer and enter it in Settings or with painite config set token.

A step says it uses a placeholder, or Unblur fails

The model isn't installed on the server. Run sudo painite-server models list to check, then sudo painite-server models pull --all --accept-license and sudo systemctl restart painite-server. Pulling downloads only what is missing.

The server says “The NVIDIA driver on your system is too old”

The server needs NVIDIA driver 580 or newer (CUDA 13). nvidia-smi shows the version. On a GeForce or RTX card, install a newer driver (for example sudo apt install nvidia-driver-580 on Ubuntu), reboot, then sudo systemctl restart painite-server. Without it, the server can't use the GPU.

macOS says PAINITE can't be opened

This release isn't notarized yet. Open System Settings › Privacy & Security and click Open Anyway, or run xattr -dr com.apple.quarantine /Applications/PAINITE.app.

Something else

Please open an issue with what you did, what happened, and the output of painite status.

Limits

  • Input: JPEG and TIFF (8 or 16-bit RGB), up to 48 megapixels and 512 MB.
  • Output: up to 192 megapixels.
  • Up to four steps per job, with one Upscale 2×.
  • The server operator can change these limits (see the server settings).

Privacy

Your photos go only to your own PAINITE server, over an encrypted connection. The server deletes uploaded photos 15 minutes after their last use, and results after 24 hours. PAINITE sends nothing to anyone else. The only internet access is the server's one-time download of the models.
