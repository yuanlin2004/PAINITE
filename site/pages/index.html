AI photo enhancement that runs on your own GPU server. Remove noise, sharpen, fix camera shake and missed focus, restore faces and upscale, from a Mac app, from Lightroom, from the command line, or by asking an AI agent such as Claude.

Get started Download v{{version}} See examples

How it works

1. Run the server on your GPU

The PAINITE server runs the AI models on an NVIDIA GPU machine on your network. It was built for the NVIDIA DGX Spark. Your photos never leave your network.

2. Enhance from your Mac, terminal or agent

The Mac app shows a live before/after preview of the area you choose, then exports the full photo. The painite command runs batches on macOS or Linux, and its MCP server lets AI agents like Claude Code and Claude Desktop preview and enhance photos for you.

3. Keep your workflow

Use PAINITE as a Lightroom desktop “Edit in” editor. Results are written beside the original, which is never changed.

What it can do

Each example is a crop at 100%. Drag across a photo to compare. Details and tips are on the Enhancements page.
